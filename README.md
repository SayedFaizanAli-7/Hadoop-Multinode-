# Hadoop-Multinode-
Automated Hadoop Multi-Node Cluster Deployment Script for setting up and configuring Hadoop services across distributed Linux nodes, including HDFS and YARN configuration.


This project provides a shell script for automating the deployment and configuration of a multi-node Apache Hadoop cluster in a Linux environment. The script simplifies the setup of Hadoop components across master and worker nodes and helps automate configuration, service setup, and cluster initialization.

Technologies: Linux, Bash/Shell Scripting, Apache Hadoop, HDFS, YARN, SSH, Multi-Node Cluster
